### What's new / 新しくなったこと

- **Open as Drive** (macOS 26 or later) — More → Open as Drive puts an archive in Finder like a USB drive. Any app can open the files inside directly; nothing is extracted until a file is opened. Read-only. The first time, turn on ZipPeek's file system extension in System Settings → General → Login Items & Extensions → ZipPeek ⓘ → FSKit Modules.
  **ドライブとして開く**（macOS 26 以降）— 「その他」→「ドライブとして開く」で、圧縮ファイルを USB メモリのように Finder につなげます。どのアプリからも中のファイルをそのまま開け、開くまで何も解凍しません。読み取り専用。初回だけ「システム設定」→「一般」→「ログイン項目と機能拡張」→ ZipPeek の ⓘ →「FSKit Modules」をオンにしてください。

Already using 0.2 or later? ZipPeek will offer this update automatically. / 0.2 以降をお使いなら、自動でアップデートの案内が出ます。
