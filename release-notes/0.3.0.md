### What's new / 新しくなったこと

- **Add and remove files inside a ZIP or 7z** — drag files into the ZipPeek window to add them, or select items and press Delete. No extracting and re-compressing. ZipPeek asks before changing anything.
  **zip・7z の中に足す・消す** — 窓にファイルをドラッグすると追加、選んで delete キーで削除。解凍して圧縮し直す必要はありません。変更の前に必ず確認します。
- **Space-key preview for 7z, rar and tar** (including .tar.gz), not just ZIP.
  **スペースキーで 7z・rar・tar（.tar.gz なども）ものぞけるように。**
- **ZIPs keep accented and kana characters whole** — names like「バックアップ」no longer turn into broken characters on Windows.
  **作る zip の名前の濁点が分かれないように** — Windows で「ハ゛ックアップ」のようになりません。
- Items can now be deleted from ZIPs made by the Mac's Archive Utility.
  Mac の「アーカイブユーティリティ」で作った zip からも削除できます。

Already using 0.2? ZipPeek will offer this update automatically. / 0.2 をお使いなら、自動でアップデートの案内が出ます。
