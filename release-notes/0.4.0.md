### What's new / 新しくなったこと

- **Peek at a ZIP on the web** — File → Look Inside a Link…: paste a link and see what's inside. Only the files you take out are downloaded.
  **リンクのままのぞく** — 「ファイル」→「リンクのままのぞく…」でリンクを貼るだけ。取り出したファイルの分だけダウンロードします。
- **More formats to create: tar.gz, tar.xz, tar.bz2, tar and dmg.** Extracting .zst and .lz works too.
  **作れる形式が増えました：tar.gz・tar.xz・tar.bz2・tar・dmg。** .zst・.lz の解凍にも対応。
- **Check for damage** without extracting, with the archive's SHA-256.
  **壊れていないかの確認**（解凍しない）と SHA-256 の表示。
- **Rename items inside**, **open a file in its app and save it back**, and **open a ZIP inside a ZIP**.
  **中で名前を変える**、**既定のアプリで開いて直したら書き戻す**、**zip の中の zip を開く**。
- **Shortcuts actions**: Compress Files, Extract Archive, Get Contents of Archive, Check Archive for Damage.
  **ショートカット App に対応**：圧縮・解凍・中身の取得・壊れていないかの確認。
- Apps extracted from a downloaded archive keep the Mac's download safety check.
  ネットから落とした圧縮ファイルの中のアプリにも、Mac の安全確認が働くようにしました。
- File names from Chinese (GBK / Big5), Korean and Western Windows can be read.
  中国語（GBK・Big5）・韓国語・西欧の Windows で作った zip の名前も読めます。

Already using 0.2 or later? ZipPeek will offer this update automatically. / 0.2 以降をお使いなら、自動でアップデートの案内が出ます。
